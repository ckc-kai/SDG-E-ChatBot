## Database Schema

`documents` — one row per source PDF:

| Column | Type | Notes |
|---|---|---|
| id | serial PK | |
| filename | text UNIQUE NOT NULL | |
| page_count | int NOT NULL | |
| content_hash | text NOT NULL | sha256, lets ingestion skip unchanged files |
| ingested_at | timestamptz NOT NULL DEFAULT now() | |

`chunks` — one row per embedded chunk:

| Column | Type | Notes |
|---|---|---|
| id | serial PK | |
| document_id | int NOT NULL REFERENCES documents(id) ON DELETE CASCADE | |
| sub_document | text | e.g. "Appendix D / 22-11...CC Effectiveness Workstream" |
| breadcrumb | text | e.g. "8 Grid Design > 8.1.7 Inspections > 8.1.7.6 Aging report" |
| section_number | text | e.g. "8.1.7.6" |
| page_start | int NOT NULL | |
| page_end | int NOT NULL | |
| chunk_index | int NOT NULL | order within the leaf section |
| content_type | text NOT NULL DEFAULT 'narrative' | 'narrative' \| 'table' \| 'figure' (table/figure not implemented yet) |
| content | text NOT NULL | |
| token_count | int NOT NULL | |
| embedding_model | text NOT NULL | e.g. "BAAI/bge-base-en-v1.5" |
| embedding | vector(768) NOT NULL | dimension from config.yaml's `local.embedding.dimensions` |
| created_at | timestamptz NOT NULL DEFAULT now() | |

Constraints: `UNIQUE (document_id, page_start, chunk_index)`, plus an
HNSW index on `embedding` (`vector_cosine_ops`) for similarity search.
